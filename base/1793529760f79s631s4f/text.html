3. Watchdog SSHFS

Проблема: SSHFS-монтирование к orangepi может отваливаться при обрыве FRP-туннеля.

Решение: cron-watchdog в root crontab:

*/5 * * * * mountpoint -q /mnt/orangepi/Proekts || /bin/systemctl restart mnt-orangepi-proekts.service

Проверить:

sudo crontab -l | grep mountpoint
systemctl status mnt-orangepi-proekts.service --no-pager
mount | grep orangepi

5. Защита SSH (fail2ban)

Файл: /etc/fail2ban/jail.d/sshd.local

[sshd]
enabled  = true
port     = ssh
filter   = sshd
backend  = systemd
maxretry = 3
findtime = 1h
bantime  = 24h
ignoreip = 127.0.0.1/8 ::1

Плюс — SSH настроен только по ключам (PasswordAuthentication no).

Проверка:

sudo fail2ban-client status sshd
sudo fail2ban-client banned

6. IPv6 отключён

Файл: /etc/sysctl.d/99-disable-ipv6.conf

net.ipv6.conf.all.disable_ipv6 = 1
net.ipv6.conf.default.disable_ipv6 = 1
net.ipv6.conf.lo.disable_ipv6 = 1

Зачем: nginx раньше ходил на [::1]:8040, IPv6 не работал → таймауты 1–3 сек. После отключения — сайт летает (138 ms локально, 802 ms снаружи).

Проверка:

sysctl net.ipv6.conf.all.disable_ipv6   # = 1
sudo grep -rn "\[::1\]" /etc/nginx/     # пусто
