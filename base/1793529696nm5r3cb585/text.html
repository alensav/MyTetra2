18.5. Автоматическое тестирование бэкапов

Раз в месяц — проверять, что бэкапы восстанавливаются.

Скрипт /root/scripts/test_restore.sh

#!/bin/bash
set -uo pipefail
BACKUP_DIR="/root/backups/proekts"
LOG="/var/log/test_restore.log"

log() { echo "$(date '+%Y-%m-%d %H:%M:%S') $*" >> "$LOG"; }

LATEST=$(ls -t "$BACKUP_DIR"/mysql-proekts-*.sql.gz 2>/dev/null | head -1)
if [[ -z "$LATEST" ]]; then
    log "ERROR: no backup found"
    exit 1
fi

log "Testing restore: $LATEST"

mysql -e "DROP DATABASE IF EXISTS proekts_test; CREATE DATABASE proekts_test CHARACTER SET utf8mb4;"

if gunzip < "$LATEST" | mysql proekts_test 2>/dev/null; then
    ORDERS=$(mysql -N -e "SELECT COUNT(*) FROM proekts_test.orders;")
    log "OK: restored proekts_test, orders=$ORDERS"
    mysql -e "DROP DATABASE proekts_test;"
else
    log "ERROR: restore failed"
    exit 1
fi

log "=== DONE ==="

Cron

0 4 1 * * root /root/scripts/test_restore.sh

18.6. Что нужно от вас

  1. Создать бота (@BotFather), узнать chat_id (@userinfobot).

  4. Cron: /etc/cron.d/monitor-proekts.
  5. Скопировать /root/scripts/backup_proekts.sh, протестировать.
  6. Cron: /etc/cron.d/backup-proekts.
  7. Скопировать /root/scripts/test_restore.sh, cron 0 4 1 * *.
