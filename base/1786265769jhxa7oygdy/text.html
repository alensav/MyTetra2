Alexandrie - подробную рабочую инструкцию по использованию

📚 Что такое Alexandrie?

Alexandrie — это современная платформа для:

  • 📝 Создания и управления документами
  • 👥 Совместной работы в командах

  • 📎 Вложений и мультимедиа
  • 🔍 Поиска по всем документам

Шаг 1: Создание Workspace (рабочего пространства)

Workspace — это как папка, где будут храниться ваши документы.

Через веб-интерфейс:

  1. Нажмите кнопку "+ New workspace" (слева, в разделе Workspaces)
  2. Введите название: например, "Мои проекты"
  3. Выберите цвет (опционально)
  4. Нажмите "Create" или "Save"

Или через терминал (API):

bash

# Создание workspace через API (замените токен)

curl -X POST http://localhost:8200/api/workspaces \

-H "Authorization: Bearer ВАШ_ТОКЕН" \

-H "Content-Type: application/json" \

-d '{"name":"Мои проекты"}'

Шаг 2: Создание документа

Через веб-интерфейс:

  1. На странице Dashboard нажмите "+ New document"
  2. Выберите Workspace (например, "Мои проекты")
  3. Введите заголовок: "Мой первый документ"
  4. Начните писать текст в редакторе

## Шаг 3: Работа с вложениями


1. В редакторе документа нажмите иконку **"Attach"** (скрепка)

2. Выберите файл с компьютера (изображение, PDF, архив и т.д.)

3. Файл загрузится и будет доступен в документе


---


## Шаг 4: Совместная работа (Teams)


### Создание команды:


1. В левом меню нажмите **"Teams"**

2. Нажмите **"+ New team"**

3. Введите название команды: **"Моя команда"**

4. Добавьте участников по email


### Приглашение пользователей:


1. В настройках команды нажмите **"Add member"**

2. Введите email пользователя (он должен быть зарегистрирован)

3. Выберите роль: `Admin`, `Editor`, `Viewer`


---


## 🔍 Шаг 5: Поиск документов


1. Нажмите **"Search or ctrl + q"** (или нажмите `Ctrl+Q`)

2. Введите ключевое слово

3. Результаты появятся в реальном времени


---


## 📋 Шаг 6: Настройка профиля


1. Нажмите на свое имя (**alensav**) в левом меню

2. Выберите **"Settings"** или **"Profile"**

3. Настройте:

- Аватар

- Email

- Пароль

- Язык интерфейса (поддерживаются: English, Korean, Italian)


---


## ПРАКТИЧЕСКИЙ ПРИМЕР: Создание документа "План проекта"


### Шаг 1: Создайте Workspace

1. Нажмите **"+ New workspace"**

2. Название: **"Проект Docker"**

3. Нажмите **"Create"**


### Шаг 2: Создайте документ

1. Нажмите **"+ New document"**

2. Заголовок: **"План настройки Docker"**

3. Выберите workspace: **"Проект Docker"**


### Шаг 3: Напишите план (в редакторе):


```markdown

# План настройки Docker


## 1. Цель проекта

Создать рабочее окружение для разработки с использованием Docker.


## 2. Задачи

- [ ] Установить Docker

- [ ] Настроить Portainer

- [ ] Развернуть Nginx

- [ ] Настроить мониторинг (DockMon)


## 3. Команда

| Имя | Роль |

|-----|------|

| alensav | Администратор |

| user2 | Разработчик |


## 4. Сроки

- **Начало:** 1 августа 2026

- **Завершение:** 15 августа 2026


## 5. Ресурсы

- [Документация Docker](https://docs.docker.com)

- [Portainer](http://localhost:9000)

- [DockMon](https://192.168.1.124:8001)

Шаг 4: Сохраните документ

  1. Нажмите "Save" или Ctrl+S

Создание вложенных документов:

  1. В списке документов нажмите "..." (рядом с документом)
  2. Выберите "Add child" или "Создать поддокумент"

Шаг 8: Экспорт документов

Экспорт в Markdown:

bash

# Через API (замените ID документа)

curl -X GET http://localhost:8200/api/documents/123/export/markdown \

-H "Authorization: Bearer ВАШ_ТОКЕН" \

-o document.md

Экспорт в PDF:

  1. Откройте документ
  2. Нажмите "Export" → "PDF"
  3. Нажмите "Download"

Шаг 9: Управление Workspace

Удаление Workspace:

  1. В левом меню наведите на Workspace
  2. Нажмите "..." → "Delete"
  3. Подтвердите удаление (все документы будут удалены!)

Переименование Workspace:

  1. Наведите на Workspace
  2. Нажмите "..." → "Rename"
  3. Введите новое название

Полезные советы:

  1. Горячие клавиши:
    • Ctrl+Q — поиск
    • Ctrl+S — сохранить документ
    • Ctrl+B — жирный текст
    • Ctrl+I — курсив
    • Ctrl+K — вставить ссылку
  2. Организация:
    • Используйте Workspace для разных проектов
    • Создавайте документы внутри Workspace
    • Используйте теги (если поддерживается)
  3. Совместная работа:
    • Создайте Team для совместной работы
    • Назначайте роли (Admin, Editor, Viewer)
    • Используйте комментарии в документах
  4. Резервное копирование:

bash

# Бэкап базы данных

docker exec alexandrie-mysql mysqldump -u root -p alexandrie > backup.sql

Что делать, если документ не сохраняется?

  1. Проверьте статус контейнера:

    2. bash

    docker compose ps

  2. Проверьте логи:

    3. bash

    docker compose logs backend --tail 20

  3. Перезапустите Alexandrie:

bash

docker compose restart

Alexandrie — это мощный инструмент для организации знаний. Вы можете:

  1. Создавать Workspace для проектов
  2. Писать документы с Markdown-разметкой
  3. Вставлять изображения и файлы
  4. Работать в команде
  5. Искать по всем документам
  6. Экспортировать в PDF/Markdown

Пример использования: Создайте Workspace "Docker", добавьте документ "План настройки" и ведите там всю документацию по вашим Docker-проектам!
