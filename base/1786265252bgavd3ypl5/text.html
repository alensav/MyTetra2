Как использовать Alexandrie:

1. Войдите в систему через веб-интерфейс

2. Загрузите образ:

bash

# Скачайте тестовый образ

docker pull nginx:latest


# Переименуйте его для вашего реестра

docker tag nginx:latest localhost:9000/my-nginx:latest


# Загрузите в ваш реестр

docker push localhost:9000/my-nginx:latest

3. Скачайте образ из вашего реестра:

bash

docker pull localhost:9000/my-nginx:latest

🛠️ Дополнительные команды:

bash

# Просмотр всех образов в реестре

curl http://localhost:9000/v2/_catalog


# Просмотр тегов образа

curl http://localhost:9000/v2/my-nginx/tags/list


# Остановить Alexandrie

cd ~/Downloads/Alexandrie-8.11.0

docker compose down


# Запустить Alexandrie

docker compose up -d


# Просмотр логов

docker compose logs -f

Настройка аутентификации:

Если хотите защитить реестр паролем:

bash

# Создайте пароль для реестра

docker run --entrypoint htpasswd registry:2 -Bbn username password > auth/htpasswd


# Запустите с аутентификацией

docker run -d --name registry \

-p 5000:5000 \

-v $(pwd)/auth:/auth \

-e "REGISTRY_AUTH=htpasswd" \

-e "REGISTRY_AUTH_HTPASSWD_REALM=Registry Realm" \

-e "REGISTRY_AUTH_HTPASSWD_PATH=/auth/htpasswd" \

registry:2
