🚀 Первые шаги внутри приложения

Теперь, когда интерфейс перед вами, рекомендую такой порядок действий для безопасного тестирования:

  1. Подключите репозиторий: Нажмите Connect Repository и выберите локальную папку или введите URL вашего репозитория (например, alensav/MyTetra2).
  2. Создайте тестовую задачу: Не начинайте сразу со сложного кода. Создайте в GitHub простой Issue (например: "Добавь файл README.md с описанием проекта").
  3. Запустите агента: Выберите этот Issue в приложении и нажмите Start Session.
  4. Выберите режим Plan: Пусть агент сначала предложит план действий. Оцените его, одобряйте шаги и наблюдайте, как он работает в изолированном git worktree.
  5. Изучите Canvas: Обратите внимание на двустороннюю доску, где агент показывает изменения кода и результаты терминала в реальном времени.

Если на каком-то этапе интерфейс покажется непонятным, агент выдаст ошибку или вы захотите настроить интеграцию с вашими CI/CD пайплайнами — просто напишите. Я помогу разобраться с конкретным сценарием!

Удачи в работе с новым агентским интерфейсом!
