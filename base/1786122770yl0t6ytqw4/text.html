DockMon

Теперь вы видите главную панель управления (Dashboard). Давайте разберемся, что здесь к чему.

📊 Что вы видите на панели:

Основная статистика:

  • Hosts: 1 онлайн (ваш компьютер)
  • Containers: 5 всего (3 запущены, 2 остановлены)
  • Alerts: 0 (всё работает стабильно)
  • Updates: 0 (нет обновлений)

Использование ресурсов хоста:

  • CPU: 0.2% (почти нет нагрузки)
  • Mem: 5.2% (оперативной памяти используется мало)
  • Net: 518 B/s (минимальный сетевой трафик)

Контейнеры (Top Containers):

  1. docker — [running] (основной демон Docker)
  2. my-app-web-1 — [running] (ваш Nginx)
  3. nginx-test — [exited] (остановлен)

🎯 Что можно делать в DockMon:

1. Просмотр всех контейнеров

В левом меню нажмите "Containers" — увидите список всех контейнеров с их статусом.

2. Просмотр логов

Нажмите на любой контейнер → откроется страница с логами в реальном времени.

3. Управление контейнерами

На странице контейнера есть кнопки:

  • Start — запустить остановленный
  • Stop — остановить запущенный
  • Restart — перезапустить
  • Logs — посмотреть логи

4. Мониторинг ресурсов

На вкладке "Host" можно увидеть детальную статистику по CPU, памяти, диску и сети.

🔧 Настройка оповещений:

  1. Нажмите "Settings" (шестеренка в левом меню)
  2. Настройте уведомления:
  • Telegram — отправлять уведомления в Telegram-бот
  • Email — оповещения по почте
  • Slack — для командной работы

🚀 Полезные действия:

Запустить остановленный контейнер:

  1. Перейдите в "Containers"
  2. Найдите nginx-test (статус Exited)
  3. Нажмите на него → кнопка "Start"

Добавить новый хост:

Если у вас есть другие серверы с Docker:

  1. Нажмите "Hosts" → "Add Host"
  2. Введите IP-адрес и настройте подключение

📱 Мобильный доступ:

DockMon адаптирован для мобильных устройств:

text

https://ВАШ_IP:8001

🐛 Если контейнер не отображается:

1. Обновите список:

В правом верхнем углу есть кнопка "Refresh"

2. Проверьте через терминал:

bash

docker ps -a

3. Если контейнер есть, но не виден в DockMon:

Перезапустите DockMon:

bash

docker restart dockmon
