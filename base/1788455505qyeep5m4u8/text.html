Linux-совет: скрытые процессы и команды с unshare

Хочешь запустить процесс в изолированном пространстве имён без Docker или LXC? Используй unshare — мощный инструмент для создания минимального "контейнера" прямо в Linux.

Пример: изолировать PID и mount namespace

sudo unshare --mount --pid --fork --uts --mount-proc bash

Теперь ты внутри изолированной оболочки:

  • новый PID namespace — ps покажет только твои процессы
  • новая точка монтирования — можно монтировать без влияния на хост
  • изолированное имя хоста (hostname)

📦 Полезно для:

  • отладки в "песочнице" без Docker
  • запуска служб в изоляции
  • изучения namespaces в Linux без сторонних тулов

🛠️ Что можно добавить:

hostname sandbox mount -t proc proc /proc

Также доступны: --net, --ipc, --user, --cgroup — можно собрать полноценный "контейнер" вручную.

Вывод: unshare — это встроенный способ Linux для запуска процессов в изоляции. Не нужен ни Docker, ни Podman, ни LXC — всё уже в ядре.
