Первый запуск

1. Запустите PCLink

Из установленного приложения:

  • Windows: Найдите "PCLink" в меню "Пуск".
  • Linux: Запустите pclinkиз терминала или найдите в меню приложений.

Источник:

python -m pclink

2. Первоначальная настройка

На момент первого запуска PCLink будет:

  1. Создайте самоподписанный SSL-сертификат для безопасной связи.
  2. Создайте конфигурационные файлы в каталоге данных вашего приложения.
  3. Откройте веб-интерфейс в вашем браузере по умолчанию по адресу https://localhost:38080.

Примечание: В вашем браузере появится предупреждение о безопасности из-за самоподписанного сертификата. Это нормально и безопасно для локального использования. Нажмите «Дополнительно» и перейдите на сайт.

3. Создайте пароль для веб-интерфейса.

Веб-интерфейс предложит вам создать пароль (минимум 8 символов). Этот пароль:

  • Обеспечивает безопасный доступ к веб-интерфейсу панели управления.
  • Включает мобильный API и службу обнаружения.
  • Это необходимо для доступа ко всему веб-интерфейсу в будущем.

4. Сопряжение мобильного устройства

После установки пароля:

  1. Перейдите на вкладку «Сопряжение» в веб-интерфейсе.
  2. На экране отобразится QR-код, содержащий информацию для подключения.
  3. Откройте мобильное приложение PCLink на своем телефоне и отсканируйте QR-код.
  4. В веб-интерфейсе появится запрос на сопряжение; нажмите «Одобрить» , чтобы авторизовать устройство.

Ваше мобильное устройство теперь подключено и может управлять вашим компьютером!

Основные правила использования

Панель управления веб-интерфейсом

Получите доступ к панели управления по https://localhost:38080адресу:

  • Просмотреть состояние сервера — проверить, работает ли API.
  • Управление устройствами — просмотр подключенных устройств, назначение ролей и отзыв доступа.
  • Генерация QR-кодов — сопряжение новых устройств.
  • Управление ссылками для общего доступа — создание и отзыв защищенных токенов для обмена файлами.
  • Управление макросами — создание и запуск автоматизированных цепочек задач.
  • Трансляция с рабочего стола — просмотр предварительного просмотра экрана ведущего в режиме реального времени.
  • Просмотр журналов — Мониторинг активности сервера.
  • Настройка параметров — отрегулируйте параметры сервера и глобальные переключатели служб.
  • Руководство по доступу — просмотр команд CLI и полезных советов для быстрого запуска.

Системный трей

PCLink работает в системном трее и обеспечивает быстрый доступ к следующим функциям:

  • Откройте веб-интерфейс — запустите панель управления.
  • Состояние сервера — проверьте, запущен ли сервер.
  • Запуск/остановка сервера — управление API-сервером.
  • Настройки — Быстрый доступ к параметрам.
  • Выход - Закройте PCLink.

Мобильное приложение

После сопряжения используйте мобильное приложение для выполнения следующих действий:

  • Управляйте мышью и клавиатурой.
  • Просматривайте и управляйте файлами (включая память телефона).
  • Просмотр системной информации и диагностики.
  • Управление воспроизведением мультимедиа.
  • Управление запущенными процессами.
  • Доступ к терминалу/оболочке.
  • Делайте скриншоты и синхронизируйте буфер обмена.
  • Используйте пользовательские макросы для автоматизации.

Конфигурация

Настройки сервера

Настройте PCLink через страницу настроек веб-интерфейса:

  • Порт сервера — измените порт HTTPS (по умолчанию: 38080).
  • Автозапуск — запуск PCLink при загрузке системы.
  • Служба обнаружения — включение/отключение обнаружения сети.
  • Глобальные переключатели служб — включение или отключение определенных функций (например, терминала, файлового менеджера) для всех устройств.

Файлы конфигурации

PCLink хранит конфигурацию в местах, специфичных для каждой платформы:

Windows: C:\Users\<username>\AppData\Local\PCLink\ Linux: ~/.local/share/PCLink/ macOS: ~/Library/Application Support/PCLink/

В состав файлов входят:

  • config.json- Настройки сервера.
  • devices.db- База данных сопряженных устройств.
  • cert.pem/ key.pem- SSL-сертификаты.
  • pclink.log- Журналы приложений.

Примечания, специфичные для Linux

  • GNOME Desktop : Установите расширения AppIndicator и KStatusNotifierItem Support , чтобы увидеть значок в трее.
  • Wayland : PCLink поддерживает создание скриншотов и работу с буфером обмена в Wayland через gnome-screenshotи wl-clipboard.
  • X11 : Для полноценного удаленного управления мышью и клавиатурой в Linux в настоящее время рекомендуется использовать сессию на основе X11.

Параметры командной строки

# Run in GUI mode (default)
python -m pclink

# Run in headless/background mode
python -m pclink --startup

# Show help
python -m pclink --help

Поиск неисправностей

Не удается получить доступ к веб-интерфейсу.

  1. Убедитесь, что PCLink запущен (найдите значок в системном трее).
  2. Проверьте порт в настройках (по умолчанию: 38080).
  3. Попробуйте https://localhost:38080(обратите внимание на https://).
  4. Проверьте настройки брандмауэра.

Мобильное приложение не может подключиться.

  1. Убедитесь, что оба устройства находятся в одной сети.
  2. Убедитесь, что сервер запущен (в веб-интерфейсе отображается "Запущен").
  3. Убедитесь, что брандмауэр разрешает входящие соединения через порт 38080.
  4. Попробуйте повторно выполнить сопряжение устройства с помощью нового QR-кода.

Предупреждения сертификата

Использование самоподписанных сертификатов вызовет предупреждения в браузере. Это нормально для локального использования. Нажмите «Дополнительно» и «Перейти на localhost».

Предупреждения о безопасности и антивирусной защите

Поскольку PCLink включает в себя мощные функции, такие как удаленный доступ к командной оболочке и имитация мыши/клавиатуры, он иногда может быть помечен эвристическими антивирусными сканерами как ложное срабатывание . PCLink — это полностью открытый исходный код. Для решения этой проблемы используйте официальный установщик или добавьте его PCLink.exeв список исключений.

Порт уже используется

Если порт 38080 уже занят, измените порт сервера в настройках веб-интерфейса и перезапустите сервер.

Безопасный режим расширений

Если сервер три раза подряд зависнет при запуске, система расширений будет автоматически отключена. Как сбросить настройки: удалите проблемное расширение, перейдите в веб-интерфейс → Настройки, повторно включите систему расширений и перезапустите сервер.
