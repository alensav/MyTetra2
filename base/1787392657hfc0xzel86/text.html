Rezolus_NOTES


это агент телеметрии производительности Linux, который предоставляет подробную информацию о поведении системы с помощью эффективных инструментов с низкими затратами.

Из вывода видно, что у вас не установлен язык программирования Rust и его менеджер пакетов Cargo, которые необходимы для сборки Rezolus из исходников.

Вот что нужно сделать:

1. Установите Rust и Cargo

Самый простой способ - использовать rustup:

bash

curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh

Во время установки выберите вариант 1 (default installation).

После установки перезагрузите терминал или выполните:

bash

source ~/.cargo/env

Проверьте установку:

bash

cargo --version
rustc --version

2. Соберите Rezolus

Теперь можно собирать проект:

bash

cd ~/rezolus

# Для разработки (неоптимизированная сборка)
cargo build

# Для продакшена (оптимизированная сборка)
cargo build --release

3. Запустите Rezolus

Для запуска с примером конфига (требуются права sudo для доступа к perf_events):

bash

sudo target/release/rezolus --config configs/example.toml

4. Проверьте метрики

В другом терминале:

bash

curl --silent http://localhost:4242/vars

Примечание: Если вы используете Astra Linux (как указано в приглашении), возможно, Rust уже есть в репозиториях. Можно попробовать:

bash

sudo apt update
sudo apt install rustc cargo

Но рекомендую использовать rustup, так как он устанавливает последнюю версию и позволяет легко обновляться.
