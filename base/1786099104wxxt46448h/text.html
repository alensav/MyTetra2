Теперь вы видите главную панель управления Portainer. Давайте разберемся, что делать дальше.

📊 Что вы видите на экране:

Вас встретил раздел "Environments" (Среды). Здесь отображается ваша локальная среда Docker с названием "local".

  • Тип: Docker (это ваш локальный Docker)
  • URL: unix://var/run/docker.sock (подключение к Docker через сокет)

🚀 Что делать дальше:

1. Выберите среду local (нажмите на нее)

Нажмите на название "local" — вы перейдете в панель управления этой средой.

2. Изучите главное меню (слева)

После выбора среды у вас появится полное меню:

text

📊 Dashboard — Главная страница со статистикой

📦 Containers — Список всех контейнеров (запущенные/остановленные)

🖼️ Images — Список Docker-образов

Volumes — Тома (хранилища данных)

🌐 Networks — Сети Docker

📚 Stacks — Docker Compose проекты

📋 Events — События Docker в реальном времени

⚙️ Settings — Настройки

3. Первый шаг — посмотрите контейнеры

Нажмите "Containers" в левом меню. Вы увидите:

  • Все запущенные контейнеры
  • Остановленные контейнеры
  • Статистику использования ресурсов

💡 Основные действия в Portainer:

📦 Запустить новый контейнер:

  1. Нажмите "Containers" → "Add container"
  2. Введите:
    • Name: nginx-test
    • Image: nginx:latest
    • Port mapping: 8080:80
  3. Нажмите "Deploy"
  4. Откройте http://localhost:8080 — увидите приветствие Nginx!

📚 Создать Stack (docker-compose):

  1. Нажмите "Stacks" → "Add stack"
  2. Введите имя, например: my-app
  3. В поле "Web editor" вставьте код:

    4. yaml

    version: '3'

    services:

    web:

    image: nginx:latest

    ports:

    - "8081:80"

  4. Нажмите "Deploy"

📊 Посмотреть логи контейнера:

  1. Перейдите в "Containers"
  2. Нажмите на любой контейнер
  3. Перейдите на вкладку "Logs"
  4. Увидите логи в реальном времени

🔧 Важные настройки:

Настройка безопасности:

В левом меню → Settings → General:

  • Включите "Force HTTPS only" (принудительно использовать HTTPS)
  • Настройте "Authentication" (время сессии, сложность пароля)
